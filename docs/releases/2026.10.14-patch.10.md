## Intended changes

- Build native macOS Apple Silicon and Windows x86_64 installers from the root repository's exact maintained-fork revisions.
- Build the Linux VPS stack as versioned GHCR images with a release deployment compose file.
- Check the latest published eLLMsha GitHub release from the desktop and show a download action beside the sidebar toggle.
- Download and verify the complete platform installer, then open its DMG or EXE through the operating system. Opening an installer does not automatically terminate running agent tasks or replace the application.
- Keep signing keys in CI secrets and a temporary runner keychain. Every CI macOS build requires a Developer ID Application identity and notarization; Windows installers remain unsigned. Manual verification does not publish a release.
