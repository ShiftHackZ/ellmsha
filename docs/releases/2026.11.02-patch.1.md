# eLLMsha — November 2, 2026

## New

- Interactive terminal tabs are shared by you and your agent. Type commands, inspect live output, use full-screen tools such as `watch`, send Ctrl+C, resize the terminal, or close the session and its owned processes. Desktop terminals run locally; WebUI terminals run on the server, inside the container for Docker deployments.
- Open file and BMAD document previews refresh after an agent changes the source while preserving the selected tab and unsaved edits.
- A toolbar button beside the Files toggle shows or hides the preview panel without closing its tabs.

## Improvements and fixes

- Settings → Memory now separates Memory Hub from embedding-model settings and preserves unfinished configuration when switching tabs.
- The update icon appears beside Settings, and beside the theme switch inside Settings, only when a newer release is available.
- Fixed the blank, unresponsive USB security-key dialog in the macOS in-app browser. Cancel, Escape and native close remain available when the renderer fails to start. AWS Console sign-in has been confirmed in the earlier signed local build; Google security-key sign-in remains unverified and may require another 2FA method.
- Improved Copilot tool compatibility and shared project-rule preloading across agent runtimes.
- Desktop, WebCLI and Docker builds include the shared terminal tools and required runtime resources.

- Fixed Windows installer packaging checks and preserved the release date format in installer filenames.

## Support notes

- The terminal manages processes created through its own sessions; it does not adopt unrelated processes started outside the app.
- macOS Apple silicon installers are Developer ID signed and notarized. The Windows x64 installer is unsigned; native Windows installation/runtime checks remain separate from package-build verification.
- Figma integration is being developed separately and is not included in this baseline release.
