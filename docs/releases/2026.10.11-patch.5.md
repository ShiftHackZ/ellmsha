# eLLMsha v2026.10.11 Patch 5

## Better recall, clearer evidence

Project memory now distinguishes project facts, global knowledge and chat history more reliably. Retrieval understands project aliases, exact identifiers, dated “latest” questions and continuation context. Broader searches retain pagination and completeness information, and responses carry source caveats and partial-failure warnings through to the agent.

## What's new

- **Scoped memory retrieval:** project and global scopes, source dates, exact-ID handling and bounded enumeration with explicit completeness status.
- **Code graph on demand:** agents can inspect, allocate and release a graph runtime, then reload it when needed. Releasing a runtime preserves its persistent index; active queries hold a lease.
- **Current architecture guidance:** agents are directed to inspect the repository and available code graph tools for current implementation facts, while memory supplies historical decisions and context.

## Fixes

- Preserve retrieval health and warnings in explicit memory searches and context responses, including degraded results that still contain useful evidence.
- Bind context searches to the active project and validate aliases before passing them to the memory gateway.
- Keep imported source dates and substantive evidence relevant to recency queries; report unknown identifiers and incomplete lists honestly.
- Route chat-history requests to scoped history tools and preserve full-source caveats within retrieval limits.
- Propagate MCP tool errors and reject malformed or non-object tool arguments before dispatch.

## Download and install

Download **eLLMsha-2026.10.11-patch.5-mac-arm64.dmg** below and replace eLLMsha in Applications. Existing chats, memory and account connections use the persistent eLLMsha Desktop profile.

The macOS Apple Silicon build is **ad-hoc signed**, not Developer ID signed or notarized. Windows and Linux packages are not included.

## Verification and limits

Acceptance covered scoped gateway retrieval, complete pagination over a bounded corpus, project-scoped chat history, actual code graph lifecycle calls and preservation of index data. Fresh GPT and Qwen conversations both recovered the main latest-task fact from retrieved evidence; Qwen still omitted caveats and made a factual-detail error. Retrieval improvements do not make all models equally accurate or fast.

Current-architecture tool selection remains agent guidance, not a mandatory tool-call gate. Full memory reindexing is not exposed as an agent tool in this release; it requires coordinated service lifecycle handling. Claude inference and Windows/Linux runtime checks remain unverified.
