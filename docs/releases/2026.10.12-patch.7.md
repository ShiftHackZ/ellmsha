# v2026.10.12 Patch 7 — more reliable tools and browser actions

This release combines the previously unpublished Patch 6 improvements with the fixes verified in Patch 7.

## Highlights

- **More reliable in-app browser control.** Actions activate the intended tab and verify its actual input destination. Duplicate URLs retain independent tab identities; closed targets return an error rather than silently switching to another tab. Input remains correctly targeted when another application is active, without forcing application focus.
- **Useful guidance for dynamic tools.** Native tool discovery includes the relevant server documentation, follows paginated catalogs and refreshes changed schemas. An incomplete refresh preserves the previous complete catalog. Server documentation remains labelled as tool-provided information.
- **A working brief for multi-step tasks.** Agents can retain conversation-local constraints with references to the user's instructions, reconcile later corrections and record unit, integration, UI and manual evidence separately. Guidance distinguishes current architecture checks through CodeGraph/source from historical questions through memory/chat history.
- **Better recovery from empty model responses.** One bounded recovery attempt retains tools and existing approval checks. Repeated empty responses report an incomplete task. Tool calls emitted during tools-disabled finalization receive a terminal error without being executed; compatible reasoning-stream aliases are also supported.
- **Smaller integration fixes.** Automatic titles have additional privacy guards. The macOS/Linux Linear adapter normalizes supported embedded-image markup before extraction. Computer Use can clear an editable field with an explicitly empty value.
- **Isolated evaluation sessions.** Native test conversations can use only explicitly selected MCP configurations, leaving ordinary chats' defaults intact. This is tool/configuration isolation, not an operating-system sandbox; unsupported ACP runtimes reject the option.

## Verification

- Installed macOS checks used real models and independent observations on disposable, noncommercial fixtures. Bounded assisted scenarios passed for browser input, same-URL tabs, closed-target rejection, MCP guidance/discovery/refresh, the Linear adapter and native field clearing.
- An actual empty-response recovery continued to tool execution. A freshly launched Computer Use helper retained access after the installed update with its binary identity unchanged; no new OS grant was applied during that check.
- Earlier Patch 6 checks covered task-brief reconciliation, CodeGraph indexing/source verification and a synthetic automatic-title case. These remain prior evidence rather than claims of new Patch 7 runs.
- Focused Rust, TypeScript and UI regression checks, component test gates, package verification and independent reviews passed. Real Electron/Puppeteer checks also confirmed that browser input left both the app composer and another application's focused field unchanged.

These were bounded, assisted evaluations. They do not guarantee autonomous model accuracy or the absence of every regression. Live child/fork isolation, forced-compaction recovery and long-session guidance growth remain outside the live verification scope. Automatic-title guards are not a comprehensive secret detector.
