# eLLMsha v2026.10.10 Patch 3

## Highlights

- Updated the managed Codex CLI to **0.162.1**, restoring live GPT-6 model discovery. GPT-6 Astra inference and project-memory access were verified in the installed macOS app.
- Added **Managed / System / Custom** CLI selection with resolved path and version. Managed runtimes can update independently of desktop releases; active sessions retain their executable. Rollback is available when a previous managed version exists.

## Fixes

- Fixed stale persisted model catalogs rejecting models before the live runtime could validate them, and bounded model-list pagination.
- Moved harness-managed Codex skills outside user repositories while preserving discovery and project isolation.
- Fixed Codex permission-profile setup and resumed Tencent memory-tool compatibility.
- Kept network access available in Auto and Read Only modes while enforcing filesystem restrictions.
- Aligned runtime buttons, loading states and text contrast with the shared light/dark design.

## Installation and verification

Download the macOS Apple Silicon DMG and replace eLLMsha in Applications. Existing chats and memory remain in the persistent eLLMsha Desktop profile.

The build is ad-hoc signed, not Developer ID signed or notarized. Windows and Linux binaries are not included.

Verified scenarios include live GPT-6 Astra, project-memory reads, resumed network access, denied writes in Read Only mode, runtime source selection, and native light/dark UI. Cross-version managed rollback has focused test/review coverage but was not exercised live; Claude inference was not tested.
