# v2026.10.12 Patch 6 — reliable tool use

Unpublished, installed candidate. On 2026-10-12 the verified macOS DMG replaced the daily-use installation and retained its profile. Real GPT/Qwen QA chats were created on an independent synthetic project and preserved. **Live acceptance is partial:** task context and CodeGraph passed; background browser input timed out; native MCP guidance remained blocked by insufficient per-chat plugin isolation. These results do not establish regression-free operation.

## Changes

- **Exact browser targets.** In-app tab operations and DevTools observations/actions use the same stable target. Switching tabs invalidates old element snapshots. Closed targets fail explicitly; timed-out mutations are not replayed automatically. A transient discovery failure can recover.
- **Guidance when tools are discovered.** Native agents retain MCP server instructions and receive bounded integration documentation with lazily discovered schemas. Complete paginated catalogs refresh between model rounds; failed refreshes retain the previous complete snapshot. Parent, child, fork and dynamically added integrations use the same path.
- **A small working brief per chat.** Explicit user constraints and acceptance criteria can be recorded with source-message references in existing conversation metadata. Revision checks reject stale updates, newer user messages require reconciliation, and reset/fork cannot inherit stale references. Evidence distinguishes unit, integration and UI checks and remains model-reported.
- **Practical source selection.** Tool guidance directs current-architecture questions to the relevant fresh code graph and source files, past decisions to memory, and prior conversations to chat history. This guidance is not a guarantee of model compliance.
- **Safer automatic titles.** New chats start with a neutral title. Common credential-bearing prompts are excluded from automatic list metadata; explicit user renames are preserved. Detection is conservative and cannot recognize every arbitrary secret.
- **Adapter fixes.** Computer Use accepts an empty `set_value` for clearing a field. The macOS/Linux Linear account adapter converts supported native image nodes to the input its image tool accepts, preserves account isolation and drains large responses completely.

## Limits and rollout

- The model still interprets user intent and evidence. Existence of a referenced tool result is checked; semantic completion is not certified by the harness.
- Native HTTP integrations without observed notifications refresh on a 60-second fallback. Updated initialize instructions require reconnect. External Codex/ACP clients control their own MCP consumption.
- Automatic Linear conversion is not enabled on Windows; the existing skill helper remains available there.
- No Screen Recording permission changes, forced database replacement, production load experiments or external service writes are included.
- This candidate is installed locally but not published. Full live acceptance is incomplete for the reasons above; cross-platform packaging remains outside this run.
- Earlier automated browser tests used independently owned temporary Chrome profiles. The subsequent installed evaluation exposed a background-webview input timeout not demonstrated by those tests.
