# eLLMsha — October 22, 2026

## New

- Desktop browser tabs now keep separate sign-ins, cookies and browsing data for each project. Chats in the same project share a browser profile; chats outside projects use a shared default profile.
- Auto Router can choose models for the main agent and its subagents. Its visual editor lets you assign different models to tasks such as coding, research and review, with separate saved settings for each mode.
- Usage statistics are available for individual chats and across the app. See input and output tokens, cached input, context size and tool usage, with global filters by date, provider and model.
- Added bundled community skills for research, writing, interface design and diagrams.

## Improvements and fixes

- Browser tabs preserve filled forms and popup windows when switching projects. Browsing history and data-clearing controls are separate for each project.
- Improved website compatibility with an updated desktop browser engine.
- Fixed browser automation hanging when an agent reconnects to an already open tab.
- Agents read project rules before starting work, including tasks delegated to subagents.
- Reduced unnecessary context sent to AI models when many tools are enabled.
- Fixed the main window taking focus when releasing a dragged desktop pet.
- Refreshed the application icon and corrected its Dock size.
